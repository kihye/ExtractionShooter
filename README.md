# Extraction Shooter Prototype

Unity 기반 탑뷰 익스트랙션 슈터 프로토타입입니다.  
거점에서 장비를 준비하고, 전투 지역에서 아이템을 획득한 뒤 탈출하는 기본 플레이를 구현했습니다.

## 개발 환경

- Unity 6000.3.23f1 / URP
- C#
- ChatGPT / Codex

## 주요 기능

- 이동, 마우스 조준, 사격 및 재장전
- 적 추적·공격, 아이템 획득 및 탈출
- Grid 인벤토리, 장비·가방 관리, Drag & Drop
- 거점 창고 및 상점 구매·판매
- 타이틀·거점·전투 씬 전환
- 아이템·장비·플레이 상태 저장 및 불러오기

## AI 활용 개발

ChatGPT와 Codex를 요구사항 정리, 구현 계획, 코드 작성·리팩터링, 버그 분석에 활용했습니다.

게임 규칙과 작업 범위를 결정하고, Unity에서 직접 플레이를 검증한 뒤 재현 조건과 로그를 바탕으로 수정 작업을 진행했습니다.

대표적인 작업은 다음과 같습니다.

- 거점과 전투 씬이 공유하는 인벤토리·장비 상태 관리
- 런타임 생성 UI를 Editor에서 편집 가능한 Scene/Prefab 방식으로 전환
- 빈 인벤토리 저장, 불러오기 시 탄약 중복, 첫 UI 갱신 문제 수정

AI가 생성한 코드를 실제 플레이 결과와 대조하며 수정하는 과정을 프로젝트에 적용했습니다.

## 실행 방법

소스 실행은 Unity 6000.3.23f1에서 프로젝트를 열고 타이틀 씬을 실행하면 됩니다.  
실행 빌드는 준비되는 대로 GitHub Releases에 게시할 예정입니다.

## 기본 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| E | 상호작용·아이템 획득 |
| Tab | 인벤토리 열기·닫기 |
| Esc | 열린 UI 닫기 |

## 개발 상태

기본 플레이와 시스템을 확인할 수 있는 프로토타입 단계입니다.  
임시 오브젝트와 간단한 UI를 활용했습니다.
